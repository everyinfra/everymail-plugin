# EveryMail repository contract

This repository owns exactly one skill: `plugins/everymail/skills/everymail/SKILL.md`. Public metadata and documentation must match its real MCP or REST contract. User intent for independent repositories overrides the old bundle's single-repository maintenance layout; the existing bundle remains untouched.

Edit this file, not the `AGENTS.md` symlink. Preserve unrelated work. Do not commit, push, publish, install into a personal host or change credentials without explicit authority. Run `python3 scripts/validate.py` for scoped local validation. Do not infer live service success from these offline checks.

No credentials, private customer data, unsupported inventory, invented benchmarks or internal provider information in this public package. Runtime catalogs determine fields, limits, availability and current prices. No skill may broaden account scopes or turn preparation into an unapproved external operation.

Repo metadata records source provenance and intended publication fields. Each independent repository owns its version; shared changes need explicit review rather than overwriting skill files from the old bundle. Keep physical Git metadata outside the iCloud-managed checkout when working on the maintainer's Mac.
