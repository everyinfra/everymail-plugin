# Support

Start with the setup and workflow documents, then check the current API catalog and account configuration. For help, contact sales@everyinfra.com or use the public repository issue tracker once the repository is published.

Include the plugin version, host version, expected behavior, redacted status and a minimal reproduction. Say whether the failure occurred during installation, discovery, an authorized API operation or final delivery. Do not attach credentials, OTPs, email bodies or proxy passwords.

Documentation: https://api.everyinfra.com/docs
